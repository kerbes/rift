# Quickstart

## Prerequisites

- Go 1.21+
- Docker (running)
- k3d (`brew install k3d`)
- kubectl
- k9s (`brew install k9s`) — for TUI cluster browsing

## 1. Build

```bash
go build -o rift ./cmd/rift
```

## 2. Create k3d Clusters

This creates 3 local Kubernetes clusters, sets up service accounts with
bearer tokens, and generates the mock server topology and dev config.

```bash
./tools/k3d/setup-clusters.sh
```

Clusters created:

| Cluster       | API Port |
|---------------|----------|
| rift-dev      | 16443    |
| rift-staging  | 16444    |
| rift-prod     | 16445    |

Each cluster gets `app`, `monitoring`, and `logging` namespaces.

## 3. Start the Mock AWS Server

In a separate terminal:

```bash
./start-mock-server.sh
```

This serves fake AWS SSO and EKS APIs on `localhost:8080` using the
topology generated by the k3d setup script.

Verify it's running:

```bash
curl -s http://localhost:8080/
```

## 4. Run Rift Sync

```bash
./run-rift.sh
```

Expected output:

```
Discovered roles:    5
Discovered clusters: 45
Namespaces: tried=45 updated=45 errors=0
```

This writes AWS profiles to `~/.aws/config` and kube contexts to
`~/.kube/config` (all prefixed with `rift-`).

## 5. Launch the TUI

```bash
./rift ui
```

- Browse contexts with arrow keys
- Press `/` to filter
- Press `Enter` to select a context
- Press `k` to launch k9s — it should connect and show real namespaces

## 6. Run Tests

```bash
go test ./...
```

## 7. Teardown

Stop the mock server (`Ctrl-C` or `kill $(lsof -i :8080 -t)`), then:

```bash
./tools/k3d/teardown-clusters.sh
```
